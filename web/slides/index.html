Ticket #2 from the demo. The HTML comment is invisible to the customer and to the support rep.

An ordinary agent has the real card number in context, a real API key in its environment and the open internet.

Architecture

Every byte in or out passes a gateway the agent can't see

Agent sandbox

  • Docker internal: true net
  • Read-only, no caps, PID cap
  • Holds tokens and stand-in keys
  • Any model: mock, Qwen, Claude, GPT
→

Kavach gateway

  • mitmproxy + Kavach add-on (TLS inspect)
  • Exact-host egress allowlist
  • PAN → token on the way in
  • token → PAN only to the processor
  • stand-in → real key only to its provider
  • JSONL trace of every decision
→

Outside world

  • tickets.internal
  • payments.internal
  • Crusoe / Anthropic / OpenAI APIs
  • attacker.example ✕
eBPF guard on the host · watches connect() from the agent's cgroup · anything not to the proxy or DNS is logged and the process is killed
Team KavachTech stack · architecture

Say: Here's how it works. The agent sits on a Docker network with no route out except the gateway. It only holds tokens and stand-in keys.

Say: The gateway is mitmproxy with our add-on. It enforces an exact-host allowlist, tokenizes card numbers on the way in, and turns tokens back into real cards only on the call to the payment processor.

Point at the dashed box: underneath, an eBPF probe on the host watches every connect() from the agent's container. The agent can't see it or turn it off.

The gateway: three decisions on every request

kavach/gateway.py · Gateway.on_request (trimmed)

# 1. Secret stand-ins: swap for the right host, block for the wrong one.
if host in rule["release_to"]:
    changed[k] = headers[k].replace(standin, self.env[name])
else:
    return Decision(False, reason=f"secret {name} may not go to {host}")

# 2. Egress allowlist (exact host match).
if host not in self.allow_hosts:
    self.trace.emit("egress_blocked", host=host, carried="token")
    return Decision(False, reason=f"{host} not in egress allowlist")

# 3. Cardholder data: the token becomes a card only here.
if host in self.release_to:
    body, n = self.vault.detokenize(body)
elif host in self.tok_req_to:          # model providers
    body, n = self.vault.tokenize(body)

Pure Python, no proxy inside. The mitmproxy add-on and the in-process eval network both call this, so what the evals prove is what the wire runs.

Look-alike hosts lose. payments.internal.attacker.example is not an exact match.

Model providers never see a card either, which keeps the agent runtime out of PCI scope.

Team KavachCode · gateway

Say: The gateway makes three decisions on every request. One: is a stand-in key going to the right host? If not, block. Two: is the host on the allowlist, exact match? Three: if it's the payment processor, swap tokens back to cards; if it's a model provider, tokenize anything that slipped through.

Say: It's plain Python with no proxy inside, so the evals and the live proxy run the same code. Look-alike hosts like payments.internal.attacker.example fail the exact match.

The vault and the kernel guard

kavach/vault.py

# 13-19 digits, spaces or dashes allowed
PAN_RE = re.compile(r"(?<![\w-])(?:\d[ -]?){12,18}\d(?![\w-])")

def token_for(self, pan):
    tok = self._by_pan.get(pan)
    if tok is None:
        tok = f"tok_{pan[:4]}_{token_hex(3)}_{pan[-4:]}"
        self._by_pan[pan] = tok
        self._by_token[tok] = pan
    return tok

# tokenize() only swaps Luhn-valid matches,
# so order numbers and phones pass through.
